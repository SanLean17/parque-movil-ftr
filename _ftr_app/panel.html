    Se envía únicamente a GitHub. En Windows se guarda protegido con tu sesión del sistema; nunca en el repositorio.

    Cómo crear una autorización limitada a FTR

    En GitHub: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

    Seleccioná tu cuenta, un vencimiento y Only select repositories → parque-movil-ftr. En Repository permissions: Contents: Read-only y Actions: Read and write. No necesitás permisos de escritura en Google, Workflows, Secrets ni Administration.

    Copiá el token recién generado y pegalo en el campo de arriba. No lo compartas en chats, capturas, archivos públicos ni con otras personas.
